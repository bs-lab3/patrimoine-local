# patrimoine-local

Mentions légales d'une application **personnelle** de consultation de comptes
bancaires, en lecture seule, via l'API d'agrégation DSP2 d'Enable Banking Oy
(prestataire agréé par la FIN-FSA).

Ce dépôt ne contient **que** les deux pages exigées pour l'enregistrement de
l'application :

- `CONFIDENTIALITE.md` — politique de confidentialité
- `CONDITIONS.md` — conditions d'utilisation

Aucun code, aucune donnée bancaire, aucune donnée personnelle.
